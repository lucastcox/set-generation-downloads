# Set Generator downloads

[Download SetGenerator.exe](https://github.com/lucastcox/set-generation-downloads/releases/latest/download/SetGenerator.exe)

Windows desktop app for Standard TBQ and XP5 set generation.

1. Download and run `SetGenerator.exe`.
2. Add XML, QPro, or QWriter question banks.
3. Configure the material and generate sets.

Python is not required. Question banks are supplied separately.

Successful tested builds update the latest release automatically. Each release includes a SHA-256 checksum in `SHA256SUMS`.
